# 🚀 DevGest

O **DevGest** é um projeto Full Stack desenvolvido com o objetivo de praticar e demonstrar conhecimentos em desenvolvimento web.

Atualmente o projeto está em fase inicial de desenvolvimento e novas funcionalidades serão adicionadas ao longo do tempo.

## 🛠️ Tecnologias

### Front-end
- React
- Vite
- React Router
- CSS

### Back-end
- Node.js
- Express

### Banco de Dados
- PostgreSQL *(em breve)*
